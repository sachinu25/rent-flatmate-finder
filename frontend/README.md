# Frontend — Rent & Flatmate Finder

Next.js 16 (App Router) + React 19 + Tailwind CSS v4.

```bash
cp .env.example .env.local   # BACKEND_URL, NEXT_PUBLIC_SOCKET_URL, NEXT_PUBLIC_SITE_URL
npm install
npm run dev                  # http://localhost:3000 (expects the API on BACKEND_URL)
```

Scripts: `dev`, `build`, `start`, `lint`, `typecheck`.

See the [root README](../README.md) for architecture, features and deployment.
